# Data Visualization Laboratory

This repository contains practical programs for the Data Visualization Laboratory (Academic Year 2026–2027).

## Experiments
1. Introduction to Various Data Visualization Tools
2. Basic Visualization in Python
3. Basic Visualization in R
4. Introduction to Tableau and Installation
5. Connecting to Data and Preparing Data for Visualization
6. Data Aggregation and Statistical Functions
7. Creating Scatter Plot Maps in Tableau
8. Data Visualizations: Charts, Graphs, and Data Mapping
9. Basic Dashboards
10. Storytelling in Tableau

## Requirements
- Python 3
- pandas
- matplotlib
- seaborn
- plotly
- Tableau Public for the Tableau interface-based activities
- R for Experiment 3

Install Python libraries:
```bash
pip install pandas matplotlib seaborn plotly
```

Run a Python experiment from this folder, for example:
```bash
python Exp2_Basic_Visualization_Python.py
```

CSV files used by the experiments are included in this repository. For Tableau-only steps, follow the experiment algorithm in the lab manual and connect Tableau Public to the provided CSV file.
